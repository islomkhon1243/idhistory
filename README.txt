ИСЛОМХОН × ДИЯРА — LOVE STORY
================================

БЫСТРЫЙ ЗАПУСК
1. Распакуйте архив.
2. Откройте index.html двойным кликом.
3. Для полноценной проверки лучше запустить через локальный сервер:
   - VS Code + расширение Live Server
   - или: python -m http.server 8000

ФОТОГРАФИИ
Положите свои файлы в assets/images/ с такими именами:

hero.jpg
story-1.jpg
story-2.jpg
story-3.jpg
gallery-1.jpg
gallery-2.jpg
gallery-3.jpg
gallery-4.jpg
gallery-5.jpg

Можно использовать другие имена — тогда поменяйте src в index.html.

МУЗЫКА
Положите песни в assets/music/:

song-1.mp3
song-2.mp3
song-3.mp3

Названия треков меняются в начале файла script.js:

const playlist = [
  { title: "Название — Исполнитель", file: "assets/music/song-1.mp3" },
  ...
];

Песни идут по очереди. Дополнительно включено переключение по таймеру:
const autoNextAfterSeconds = 90;

Если нужна смена ТОЛЬКО после окончания песни:
const autoNextAfterSeconds = 0;

ДАТА ОТНОШЕНИЙ
В script.js найдите:

const relationshipStart = new Date("2024-02-14T19:30:00");

и замените на вашу дату.

ТЕКСТЫ
Все подписи, история, причины любви и письмо находятся прямо в index.html.
Просто замените мои примерные тексты на ваши настоящие.

ВАЖНО ПРО АВТОЗАПУСК МУЗЫКИ
Современные браузеры запрещают автоматическое воспроизведение звука без действия пользователя.
Поэтому музыка запускается после кнопки «Открыть нашу историю» — это правильный и надёжный вариант.

РЕКОМЕНДАЦИИ ПО ФОТО
- hero.jpg: вертикальная фотография, желательно 4:5
- story-1/2/3: горизонтальные или универсальные
- gallery: можно смешивать вертикальные и горизонтальные
- желательно WebP/JPG, 1200–2000px по длинной стороне
- старайтесь держать каждый файл до ~1 MB
